DC Circuit Calculator

วัตถุประสงค์: โปรแกรมคำนวณและวิเคราะห์วงจรไฟฟ้ากระแสตรง (DC) แบบอนุกรม ขนาน และผสม โดยผู้ใช้เพียงระบุค่าความต่างศักย์และแรงต้านทาน ระบบจะคำนวณหาค่ากระแสไฟฟ้ารวม (Current) และกำลังไฟฟ้า (Power) ของแต่ละอุปกรณ์ให้อัตโนมัติ เพื่อช่วยให้ผู้เรียนเข้าใจกฎของโอมห์และวิเคราะห์วงจรได้อย่างแม่นยำ

## วิธีใช้งาน

รันโปรแกรมด้วย `python electrical.py` แล้วระบุแรงดันและชนิดวงจร จากนั้นป้อนค่าความต้านทานคั่นด้วยเครื่องหมายจุลภาคสำหรับวงจรอนุกรมหรือขนาน โปรแกรมจะแสดงค่าความต้านทานสมมูล กระแสและกำลังรวม รวมถึงแรงดัน กระแส และกำลังของตัวต้านทานแต่ละตัว

สำหรับวงจรผสม ให้ป้อนโครงสร้าง JSON โดยแต่ละเครือข่ายมีคีย์ `series` หรือ `parallel` และตัวต้านทานแต่ละตัวมี `name` กับ `resistance_ohm` เช่น:

```json
{"series":[{"name":"R1","resistance_ohm":10},{"parallel":[{"name":"R2","resistance_ohm":20},{"name":"R3","resistance_ohm":30}]}]}
```

ค่าความต้านทานต้องเป็นตัวเลขมากกว่าศูนย์ และชื่อตัวต้านทานต้องไม่ซ้ำกัน
